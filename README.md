# RuangKos - Aplikasi Jadwal Kebersihan Kos

RuangKos adalah aplikasi mobile yang dirancang untuk membantu mahasiswa dan anak kos dalam mengelola jadwal kebersihan dan pembagian tugas piket bersama teman sekamar.

## 👥 Kelompok 21
* **Nama Produk:** RuangKos
* **Mata Kuliah:** Pemrograman Mobile K

## 🚀 Core Fitur
* **Jadwal Piket:** Membuat jadwal kebersihan harian atau mingguan.
* **Checklist Tugas:** Menandai tugas yang sudah selesai dikerjakan.
* **Pengingat Otomatis:** Notifikasi saat jadwal kebersihan tiba.
* **Pembagian Tugas:** Menentukan siapa yang bertugas setiap hari.
* **Riwayat Kebersihan:** Melihat daftar tugas yang sudah selesai dan yang belum.
